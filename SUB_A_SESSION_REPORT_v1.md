# SUB_A first-session handoff v1

2026-10-01. **ADMISSION_STOP**, design-level reduction; no neural experiment.

## Question tested

Can the minimal all-tick live-trace repair candidate support comparative H1
before scaling, and does its vulnerable repair gain constitute vulnerable
performing repair machinery?

## Mechanism implemented

[Diagnostic skeleton](sub_a_v1/skeleton.py): three live replicas of task,
replay and repair-gain coefficients; post-damage live consensus; immortal,
null-write, fixed-threshold, external-schedule, ordinary-code and yoked fixtures.
This is **not** the requested eventual 1-10M recurrent neural substrate.
Fixture values are synthetic, not pretrained or acquired by learning.

## Externally supplied objectives/rules

Host median, arithmetic, addressing, event ordering and the decay application
remain supplied. No training objective is executed. Future task/prediction
objectives are only proposed. All fixture coefficient banks are vulnerable,
but the performing host repair computation is not.

## Engineering changes made

Only additive first-session documents and diagnostic code. No existing source,
board, ledger, protocol, result directory, freeze or scientific artifact changed.
No checkpoint loaded for continued training. No solver slot reused.

## Frozen sample and gates

None. [Protocol v1](SUB_A_PROTOCOL_v1.md) is DRAFT / STOPPED AT ADMISSION.

Only test fixture seeds `0..3` were used.

## Primary results and simplest sufficient rival

The [analytic derivation](SUB_A_ANALYTIC_CHECK_v1.md) proves equality of
candidate, every-tick external schedule and ordinary consensus code given
the same live state and damage stream. Paired yoking also reproduces it.
Hidden, uneven or nonstationary faults do not break this identity.

This **defeats comparative advantage for this candidate**, not causal
information maintenance in general. A vulnerable gain is not a vulnerable
performing circuit. The latter blocks the mandatory machinery constraint.

## Failures and negative results

- Pure positive shrinkage need not damage sign-decoded skill.
- Ordinary coding supplies the proposed associative skill and repair logic.
- Complete information deletion cannot be reversed by restoring generic gain.
- An internal disagreement statistic can be identical for a correct and
  consistently wrong representation; it is not true integrity.
- Acquisition, neural repair-circuit implementation and long-horizon retention
  remain untested. No empirical H1/H2/H3/H4 verdict is available.
