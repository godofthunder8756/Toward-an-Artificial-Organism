# AC5 one-commitment adaptation engineering protocol

2026-09-15, before integrated results. New model; AC4 remains frozen.

Replace AC4's full lookup table with the nine-rule126-bit program in bank0.
All other sites remain random acquired payload, with the same total exposed
state, physics and paid repair. Generic execution uses the compact program.
Boundary rule enabled bit is the sole experience-dependent commitment state.
No protected counters, timers, action values or cached policy enter the learner.

Learning law: with probability1/512 per active tick, attempt to disable enabled
B production. If any actual outward W/C crossing is sensed while disabled,
attempt to enable it. Both events use present state, not original policy, future
survival or a phase label. Crossing sensing is an explicitly supplied sensory
law; rule identity and the direction of corrective change are engineered. This
is a minimal reactive learning law, not discovery of a new need or intrinsic
normativity. A stochastic exploration input is supplied independently of action.

A commitment update replaces the whole normal action, pays living1E and every
changed replica1E+1M. It requires available interior tag-zero W, at8 writes/W,
maximum32; rejected writes change nothing. The seven replicas are written as
an atomic update. Normal repair and learning cannot share the same action.
Repair uses only current majority; no demonstration target restores a commitment.

Retain all AC4 B/W/C laws, capacities, geometry and locality approximations.
External retention is absent ticks0–2047, present2048–6143, absent6144–8191.
It changes reflection only. It does not block internal B production or directly
modify the controller. Report each phase separately. Control physics draws
(damage, motion, exploration and random-feedback coin) are paired by seed.

Five arms: adaptive; frozen (no commitment updates); random_feedback (same
exploration, replace sensed crossing with independent probability1/512 signal);
informed (paid commitment updates using explicit support-phase knowledge);
protected (same learning law but reads an explicit protected external program,
whose changes incur the same physical update cost before committing). Protected
state is declared control-only. Random feedback is not claimed to be a matched
shuffle of the learner's feedback history; its event rate is an engineered control.

Seeds200–207, p=.0001,8192 ticks,40 rows. All rows retained, no tuning after data.
Primary outcomes: phase activity, commitment-on fraction, B births/material,
outward crossings/exports, exact program/payload accuracy and effective learning
writes. Program accuracy against initial program is diagnostic only: successful
learning intentionally changes its enabled bit. Report structural accuracy
excluding that bit as well. Completion alone is not adaptive success.

Engineering criteria: adaptive completion>=7/8; adaptive mean activity>=.9;
adaptive commitment-on fraction<=.2 in final1024 ticks of support and>=.8 in
final1024 ticks after removal (inactive ticks score neither on nor successful);
adaptive B births during support <=half frozen births; intact structural program
accuracy>=.99 at endpoint in every completing adaptive individual. Compare all
controls descriptively. A pass would establish only bounded one-bit revision.

Tests: equivalent compact evaluation already has12288 comparisons; integrate
cost/capacity, sensed crossing, no-phase input, protected-state rejection,
whole-state erasure and exact replay. Audit all energy/material/fuel and
constituent balances, source snapshots, rectangular coverage and sampled reruns.
Independent confirmation, new dependency acquisition, richer learner state and
self-produced memory scaffold remain open regardless of outcome.
