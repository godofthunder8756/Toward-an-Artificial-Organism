# AC9 research decision: acquired organization must alter material demand

2026-09-15. Design direction, not an implemented experiment or a frozen protocol.

## Evidence checked before choosing this direction

The executable [scope audit](DEVELOPMENTAL_SCOPE_AUDIT_v1.json) verifies that
AC7's eight learners realize four final routing classes: two unknown binary
choices, six changed initial guesses and two initially correct guesses. Within
each mapping class, final routes are identical. AC8 confirms eight successful
remappings. This supports learned access and maintenance, not developmental
creation of a new production requirement. Deterministic learning is not itself
an objection; the missing evidence is changed material organization.

E2 already attempted history-dependent material organization. Its protocol
explicitly retains protected trained weights, a global Adam optimizer, replay,
developmental energy top-ups and standardized assay resets. Those features
cannot be imported silently into the current vulnerable-state construction.
AC1–AC8 address some of these weaknesses, but use fixed allocated trace arrays.

## Conceptual distinction

Mossio, Montévil and Longo distinguish maintenance of organization from variation
that acquires or loses constitutive constraints/functions while preserving the
dependency network. This motivates testing an actual organizational change;
their framework does not validate our simulator or make mutual dependence alone
sufficient evidence of full closure.
[Primary source](https://montevil.org/publications/articles/2016-mml-theoretical-principles-organization/).

The Black Queen hypothesis concerns evolved dependencies through adaptive loss
of costly functions in microbial communities. It suggests that losing an
alternative can create dependence, but is not evidence for within-lifetime
development or an authorization to call an externally disabled fallback
endogenously lost.
[Original paper](https://journals.asm.org/doi/10.1128/mbio.00036-12).

## Selected direction: physically allocated learned entries

Replace always-present random payload memory with a bounded pool of initially
unallocated sites. A successful experience can create an entry only by consuming
precursor/energy through available physical writing machinery. That entry must
serve subsequent resource access or another enabling function, rather than being
an unused burden. Its replicas, location, contents and occupancy are live state.

The generic interpreter may search active entries by a stored key, but cannot
hold an external key-to-address cache or correct value. Unallocated sites have
no hidden target bits and incur no fictitious maintenance demand. Their finite
capacity is supplied; allocating them is an actual material event.

Use locally available writing activity during development to determine placement.
Paired sensory histories may bias which region experiences successful learning;
the deposition rule must not read an experimenter-assigned history label. Later
put both developed individuals under the same inputs and resource availability.
If function resides in different regions, maintenance demand should follow the
physical acquired entries. This is a hypothesis, not something to enforce in
the scoring rule.

## Requirements for the first integrated implementation

1. Explicit allocated-site inventory: precursor bound on deposition, waste on
   replacement/expiry, no free creation of capacity-bearing constituents.
2. Vulnerable entry keys, values and occupancy. If any metadata is stabilized
   by physical laws, identify that scaffold rather than calling it learned memory.
3. Regional maintenance demand calculated from actual occupied functional sites.
   The existing AC4 rule maintaining W in every bank would preassign the very
   dependency this experiment needs to test; it must not remain unnoticed.
4. A declared way to seed a previously empty region's writing machinery. If
   growth requires an initial endowment, record its depletion and failed late
   growth rather than inserting an uncharged catalyst or implicit reset.
5. Acquired entries affect an enabling function and remain physically accessible
   only through maintained machinery. No independent protected learner reconstructs
   them during the assay.
6. All acquisition failures remain in the sample. Development must be one
   uninterrupted history, or every external scaffold/reset must be disclosed.

## Discriminating experiment, to be frozen after mechanism specification

Use paired histories from the same initial state, followed by a common later
environment. Compare region-specific production/repair interruptions, resource
rescue and interruption before versus after growth. Measure material demand,
function, survival and entry turnover. Historical relocation should predict
which interruption becomes damaging after growth.

Required alternatives: no growth; fixed allocation with comparable function;
location-shuffled deposition with recorded actual costs; inert entries matched
for material burden; stateless resource sampling; and protected-memory control.
Physical copying/swapping of developed entry states between regions can separate
history from current location, provided it is labeled an external counterfactual
intervention and its material accounting is explicit.

A positive result needs more than increased resource consumption: an acquired,
used organization must create the local maintenance requirement, and the resulting
maintenance must preserve that organization. A loss of a substrate that harms
every body equally is not historical individuation. A dead baseline is not a
matched demonstration of a newly acquired requirement.

## Rejected shortcuts

- More externally defined routing bits alone: richer access task, unchanged
  production organization.
- Assigning material B to a named history and stipulating B-only survival:
  the claimed dependence is placed in the condition label.
- Disabling a fallback by experimenter command and calling it developmental loss.
- Claiming new demand from sites already allocated and maintained before learning.
- Importing E2's protected optimizer/replay without extending the live-state audit.

These are design safeguards for a testable construction, not a proof that every
alternative architecture is invalid. No AC9 result exists yet. The scope audit
is completed work; this design still requires implementation and empirical tests.
