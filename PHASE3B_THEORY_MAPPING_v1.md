## What the mechanism can discriminate

The candidate operationalizes a limited, shared, simultaneously readable
message and acquired state-dependent access. This resembles a *functional*
limited-access motif associated with global-workspace accounts, but an
eight-message router or an arbitrary R9 code can implement the same observable
mapping. It does not realize or measure a workspace seat (O3), broadcast to
all possible modules, sustained ignition, reportability, or awareness.

The four posterior counters in R5 oracle belief broadcast and
R7 independent sufficient-statistic copies (both EXTERNAL, evaluator supplied) are the
sufficient-content alternative: the world has a compact, explicit finite-state
statistic even though it has no single scalar LLR adequate for all decisions.
R6 oracle selector over learned latents is also EXTERNAL and tests selection
headroom, not autonomous learning. R1 unlimited learned broadcast,
R2 monolithic recurrent, R3 private-state specialists,
R4 fixed-selector workspace, R8 learned shared encoder without bottleneck,
and R9 equal-budget unrestricted learned eight-symbol encoder are the
independently trained primary comparators. R4 is a workspace ablation;
the other five challenge
workspace value without that architecture. Optional R10 analytic bounded-code
oracle is an EXTERNAL finite-channel bound only when certified. A result
favoring a particular training recipe over the independently trained rivals
is about inductive bias and resource-constrained generalization, not a
theory-specific indicator. A learned decoder aligning streams to generative
factors does not, by itself, establish semantic access or causal necessity.
