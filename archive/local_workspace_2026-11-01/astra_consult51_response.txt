Q3. Accept rank 991 and the conditional coverage statement.

With n_q = 1,000:

    r_q = ceil(0.99 * 1,001) = 991.

Conditional on the separately fitted center, independent threshold runs, a common distance distribution and continuity:

    P[true coverage of T < 0.97]
      = P[Binomial(1,000, 0.97) >= 991]
      = approximately 5.66007e-06.

The probability is over the threshold-estimation sample. It is not the probability that an individual future run is excluded.

This is a per-threshold statement. It does not simultaneously certify all thresholds, and it does not cover distribution changes between null calibration and evaluation. With atoms or ties, use the specified d <= T rule and describe the appropriate conservative coverage bound rather than automatically asserting the continuous-distribution equality. Order-statistic coverage depends on sample size, rank and the coverage/confidence interpretation. [search.r-project.org](https://search.r-project.org/CRAN/refmans/EnvStats/html/tolIntNparCoverage.html?utm_source=chatgpt.com)

At n_q = 198 the rank is 198; at 199 it is 198. Thus 199 is the smallest count under this formula that avoids selecting the maximum. That makes your construction rule coherent, but not a universal minimum sample size for quantile estimation. The actual frozen count remains 1,000.

The 101 center runs are acceptable as a convention. The conditional coverage argument does not require the estimated center to equal the population median.

The reset/root rule needs three corrections.

First, restrict the zero-input exception:

    Graded plant at u = 0: root = 0.

    Bistable plant at u = 0:
      compute the positive stable root x_star;
      set the lower-attractor reset x_lo = -x_star.

A blanket "x0 := 0 iff u = 0" puts the bistable plant at its unstable middle equilibrium. It also conflicts with the positive stability-margin requirement.

Second, distinguish the input used to define the reset from the input applied during the trial. Solving a new equilibrium at every probed input would change the reset experiment. State exactly which row/dose null input defines x_lo and when that value remains fixed.

Third, define bisection's exact-zero, endpoint-zero and floating-point stagnation cases. One hundred iterations is a deterministic operation count, not 100 iterations of additional numerical precision. Define F, the returned bracket representative and lambda, for example:

    lambda = 1 - g * sech^2(g*x_root + u).

The local check 0 < h*lambda < 2 concerns that stable fixed point. It is not a global accuracy certificate for the noisy recursion.

The LIM offset requires more than a grid-index argument.

If the nine centered nodes are m = -4,...,4, shifting by +7 gives:

    [0.75*s_c, 2.75*s_c]
      = approximately [0.39963, 1.46531].

That interval contains the positive spinodal s_c = 0.53284. A low-attractor reset breaks the symmetry that might otherwise suggest a transition centered at zero. The finite-time, noisy mixture transition estimated by H1 need not be zero or equal to the spinodal.

Therefore, "three steps outside" establishes that zero is outside the shifted grid. It does not establish that the relevant fitted transition is outside.

The deterministic fixture can test what the gate does when supplied an outside location. It cannot establish that the stochastic LIM plant generates that location. Supply the corresponding construction argument, or revise the existing LIM parameters and claims before calibration.

Record the actual resulting ceiling per dose and readout time. Noise-free clipping thresholds do not themselves establish realization under noisy trials.
