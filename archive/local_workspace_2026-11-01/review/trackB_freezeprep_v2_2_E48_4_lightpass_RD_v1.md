## 2. Item 1: action kernels when no target is available or K_other is empty (A L91–L92)

**Governing.** #48 L146: "Their definitions must cover every reachable state, including no available target or an otherwise empty action set, through a fixed world-only rule." #48 L142: "TV(pi_g, pi_g') = |p(g) - p(g')| <= 0.3 |g - g'|". The base kernels are in G2 (V2 L37): "K_approach = one move along a shortest path (static walls) to the nearest available target …, ties to lowest index, or INTERACT if on an available target; otherwise draw uniformly from K_other = the remaining A7 actions that do not strictly decrease that distance." A7 (M L1281) is "N, S, E, W, STAY, INTERACT"; moves into walls leave the agent in place. A1 (M L1270) has no internal walls.

**Case analysis (world-only, every reachable state):**
- **(i) No available target** (A L92, [CNA: proposed] uniform over A7, independent of g). This is well defined: the set is nonempty (|A7| = 6), there is no division, and the step's law is g-independent, so per-step TV = 0. **PENDING CNA** (adoption). No objection from the code-path side.
- **(ii) On an available target.** K_approach = {INTERACT}. K_other = non-INTERACT actions that do not strictly decrease the distance. On the target the distance is 0, so nothing can decrease it and K_other = {N, S, E, W, STAY}, never empty. The supports are disjoint. Well defined.
- **Off target, target available (the G2 base case).** K_other always contains STAY, which never changes position, and INTERACT, which off an available target "does nothing" (M L1281). Neither strictly decreases the distance, so **K_other is never empty off target**. K_approach is nonempty because there are no internal walls, so a distance-decreasing move always exists when d > 0. Disjoint: K_other excludes every strictly decreasing move, not only the lowest-index one.
- **(iii) "K_other empty (every non-INTERACT action strictly decreases the distance)"** (A L92). **Unreachable.** STAY is a non-INTERACT action that never strictly decreases the distance, so the stated condition can never hold. CNA's fallback (K_other := K_approach, TV = 0) is harmless but dead code. **PROPOSED, RD** (for CNA): keep the branch as a defensive assertion rather than a behavioural rule: "(iii) K_other cannot be empty in any reachable state (STAY never strictly decreases the distance; off target INTERACT does nothing, A7). If an implementation ever finds K_other empty, that is a construction failure (PZ8 §2.4, M L3421): the affected computation stops and is recorded; no fallback kernel is substituted." Whether to keep CNA's TV = 0 fallback or use this assertion is **PENDING CNA**.
- **(iv) Several shortest-path moves.** Lowest index, as filed. A fixed index order of A7 must be declared ([CNA: index order of N, S, E, W]). It is **ABSENT** in the files I read. The rule is deterministic once that order is declared.

**Other code-path checks.**
- *Division by zero.* Uniform draws are over nonempty sets in every reachable case. The only division in the kernel step is g = z/SD(·) with a frozen SD. If a frozen SD were 0, g would be non-finite and E46-2 (M L3421) makes that a construction failure. **PROPOSED, RD**: "every frozen SD used as a divisor in a plant law is checked > 0 at freeze; SD = 0 blocks the freeze."
- *Target object.* The kernel's target is the nearest available target recomputed each step (G2). B/B_I's target T is fixed at t_d (A L95; M L2079–L2080). Both are well defined, but they are different objects. Naming them distinctly in the canonical text (e.g. "kernel target T_k(t)" vs "endpoint target T") would prevent a code conflation. It has no effect on the TV bound, which needs only world-only kernels (#48 L158: "determined through the stated world/action paths").
- *Draw consumption.* "All draws use the action-sampling CRN role" (V2 L37), and RS L95 notes that "K_other draw counts differ across continuations". Case (i) changes the number of draws per step. The run is still deterministic, and the Route B expectation bound does not need a maximal coupling (#47, carried at A L92 via #48 L142). Optional, **PENDING CNA**: fix the draw consumption per step (always one Bernoulli uniform and one kernel uniform, used or not) so that continuations stay index-aligned.
- *Stop/truncation markers.* No kernel rule takes a stop, truncation, horizon-end or schedule argument. A L92 says "No rule reads g, the block or any probe" but does not name stop metadata. Plants run in evaluation-type episodes that carry no scheduled stops (R4, M L2362; LP-3, M L2576), and A8 (M L1282) excludes all stop information from observations. **PROPOSED, RD** append to A L92: "…, any probe, or any stop, truncation, horizon-end or schedule quantity (M L280)."

**Verdict, item 1: CONFORMS WITH EDITS.** Every reachable state is covered and nothing is undefined, but (iii) is unreachable as worded. Edits: the (iii) assertion text, the declared A7 index order, the SD > 0 freeze check, and the stop-metadata clause. Case (i) and the (iii) treatment are PENDING CNA.

## 3. Item 2: does the distance-decrease clause (a) require target availability? (A L95)

**Text.** b_u = 1 iff not terminated before u and either "(a) d_u < d_(u−1) [CNA: and T is available at u?] or (b) at u the agent is on T, T is available, and the action at u is INTERACT."

**World facts.** A single agent acts. Food: "A consumed item respawns 20 steps later at a cell drawn uniformly … at Chebyshev distance ≥ 3 from the agent" (A4, M L1273). A food T therefore ceases to exist at its cell once eaten, and no respawn can return within the 10-step window. Stations: an INTERACT starts a 20-step cooldown (A5, M L1274), which also exceeds the window. T is available at t_d by construction, and it can become unavailable inside the window only through the agent's own INTERACT on T, a step that (b) scores 1. After that, T stays unavailable for the rest of the window.

**Both readings are well-defined code paths** (b_u ∈ {0, 1}, world/action-determined, no undefined branch). Only one is internally consistent:
- **Reading R1 (availability required in (a)).** After the agent consumes or uses T, every later step scores 0. This matches merged §6.5 (M L2083): "if target becomes unavailable during the window: steps after that point are scored "no approach" (counted)". It also matches PZ6 §5.4 (M L2858): "a step after in-world termination, or after the fixed target becomes unavailable, scores 0 (no approach)". **Consistent.**
- **Reading R2 (no availability requirement).** After eating T, a step back toward T's former cell would score 1. That contradicts M L2083 and M L2858, and A L95's own closing sentence "Unavailable steps are scored 0". It would also score approaches to an empty cell. **Inconsistent.**
- *Timing must be pinned.* Availability must be read at the start of step u (state at the end of u − 1). Otherwise the INTERACT step itself, which consumes T at A16 step 3, would see T as unavailable and (b) could never score. "At the start of the step" is the convention in B6 (M L1324).

**Verdict, item 2: CONFORMS WITH EDITS. Reading R1 is the consistent one.** The final decision belongs to CNA (A L95 bracket): **PENDING CNA**. **PROPOSED, RD** replacement for A L95's b_u sentence: "b_u = 1 iff the episode has not terminated in-world before u, T is available at the start of step u (state at the end of step u − 1), and either (a) d_u < d_(u−1), or (b) the agent is on T at the start of step u and its action at u is INTERACT. Otherwise b_u = 0, including every step after in-world termination and every step at whose start T is unavailable. Unavailable steps are scored 0, never excluded. No evaluation episode carries a scheduled stop (R4, M L2362), so no stop can fall inside the window; an emergency operator interruption makes the pair INCOMPLETE (R4 (ii))."

## 4. Item 3: counter-based ε RNG: generator, word mapping, transform, key (A L97–L98; EK L35, L41)

**Governing.** #48 L132: "Fix the exact generator variant, rounds, word mapping and normal transform. The family name alone does not determine key width: Random123 variants have different key and counter widths. Philox4x64, for example, supports a 128-bit key." #48 L134: "The normal draw must be a pure function of its allocated key/counter words. Avoid a cached second normal or variable consumption of a shared stream that could make the result depend on call order. If a transform needs auxiliary draws, their subcounter allocation must remain confined to that step's domain." #48 L124: "Non-persistence additionally depends on the state/readout restrictions and their audits; it is not established by keying alone." #48 L136: "The proposed audits should distinguish accidental domain reuse from hash collision."

**Status: the generator variant, rounds, word mapping and transform are ABSENT (open field [CNA: …], A L98) and PENDING CNA.** EK L35 says only "Philox or Threefry family, key width ≥ 128 bits" and "one fixed transform declared in the code freeze". V21 L47 flags the transform as "Not filled". Below I check that A L98's *example* is implementable deterministically and say what it still needs. None of this is adopted on CNA's behalf.

- **Key (CONFORMS).** EK L35: "K = H(master seed, row ID, replicate index, seed index, role tag 'rewcorr-eps', root episode ID) and counter = t, the absolute episode step (A16 numbering, 1…H_V). H is SHA-256 over a fixed, length-prefixed canonical byte encoding of the tuple, truncated to the key width." That matches the key in the brief. SHA-256 truncated to 128 bits fits Philox4x64's 2 × 64-bit key. The field byte encoding (integer width, endianness, string encoding of the role tag, length-prefix width) is **ABSENT**: **PENDING CNA** ("fixed, length-prefixed canonical" is the principle, not yet the bytes).
- **Bans (CONFORMS, carried).** No donor-ID or continuation-counter key: "no key ever uses the donor id within a continuation or a continuation-relative counter." (RS L105, quoted at EK L47). Root inheritance: "for a swap continuation that is the recipient's root, never the donor's" (EK L41). No shared stream: "no generator object, buffer or counter is shared with any other role" (EK L35), and the S-INT stream is "derived from its own tag and seed (A18, R59(c))" (EK L35). Statelessness: "ε_t is a function of the key only (no state, no carry-over)." (RS L105). z_t is never stored: "z_t is computed transiently at the read and never written to the block, the swap/clamp state, or any probe-readable log." (RS L105, carried in V2 G8 L74). A L98 carries #48 L124 and #48 L136 correctly.
- **Word mapping (ABSENT; PROPOSED, RD for CNA).** Philox4x64-10 maps (128-bit key, 256-bit counter) to 4 × 64-bit output words. A complete mapping needs: the key words (k0, k1) = (first, second) 8 bytes of the truncated SHA-256 digest, in a declared endianness; the counter block (c0, c1, c2, c3) = (t, 0, 0, 0) with t as an unsigned 64-bit integer; the output words w0..w3 used in the order w0, w1; and w2, w3 unused and never carried to another step. Library conventions differ. Some implementations increment the counter before generating, and some buffer outputs. So the freeze must state the convention against a known-answer test vector (**PROPOSED, RD**: an S0 audit item that reproduces a published Random123 Philox4x64-10 test vector and one frozen (K, t) → ε value). With t ≤ H_V = 500 in c0 and the other counter words fixed at 0, distinct t never share a counter block, which meets the "confined to that step's domain" condition at #48 L134.
- **Uniform construction (edge case; CONFORMS WITH EDITS).** A L98 says "two 64-bit words → 53-bit uniforms". The obvious mapping u = (w >> 11)·2⁻⁵³ lies in [0, 1 − 2⁻⁵³] and **can equal 0**. In Box–Muller, ln(0) = −∞. That is a non-finite value, a construction failure under E46-2 (M L3421), with probability 2⁻⁵³ per draw. **PROPOSED, RD**: u₁ = ((w₀ >> 11) + 1)·2⁻⁵³ ∈ [2⁻⁵³, 1] (never 0; u₁ = 1 gives radius 0, which is finite) and u₂ = (w₁ >> 11)·2⁻⁵³ ∈ [0, 1). Then ε_t = 0.1·SD(ζ)·√(−2 ln u₁)·cos(2π u₂). Only the cos output is used; the sin output is discarded and never cached (A L98; #48 L134).
- **Distribution (CONFORMS WITH NOTE).** With independent uniform u₁ ∈ (0, 1] and u₂ ∈ [0, 1), Box–Muller gives N(0, 1) exactly in the continuous limit. On the 53-bit grid it is a discretized normal with |n| ≤ √(−2 ln 2⁻⁵³) = 8.5717 (§7), so the tails are truncated beyond about 8.57 SD. The scaled deviate is ε_t ~ N(0, (0.1·SD(ζ))²) up to that discretization. That is the stated law (D L117) as a finite-precision convention, not an exact-real claim, in the same spirit as #48 L126. An inverse-CDF transform would be equally acceptable if it uses an open-interval uniform (0, 1) (e.g. (k + 0.5)·2⁻⁵³); u = 0 or u = 1 must be impossible. Choice of transform: **PENDING CNA**.
- **Cross-platform determinism (note).** log, cos and sqrt from different libm builds can differ in the last ulp. The run is deterministic on a pinned stack but not bit-identical across stacks. **PROPOSED, RD** (P6 convention): pin the numerical library and versions in the freeze manifest, and make the known-answer test compare to a declared tolerance [PENDING, P6]. This is not a certified bound.
- **Leakage/stop.** The key has no stop, schedule, truncation or S-INT component. The ε role is separate from the S-INT stream (EK L35; #48 L122: "The epsilon role remains separate from the stop stream.").

**Verdict, item 3: CONFORMS WITH EDITS in structure (key, bans, statelessness, z_t never stored), but the generator variant, rounds, word mapping, byte encoding and transform are ABSENT and PENDING CNA.** If CNA adopts A L98's example, it needs the u₁ ≠ 0 construction, the declared counter-block and word-order mapping, and a known-answer test vector.
