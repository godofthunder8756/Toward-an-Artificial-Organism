A3. eps keying (Lead ruling 8; attribution corrected in the v2.1 addendum: the Delegate proposed the root-ID sentence and CNA adopted it verbatim at 12:37 PM ET). The sentence, ASCII transliteration: "eps_t is keyed by (root episode ID, absolute step t). Continuations inherit the root ID and never mint a new one. Donor and pool histories use their own root IDs." CNA has now filed it with its domain (EK = CNA eps-key file 847c430d; v2.1 addendum 7b1a17d7 S2): eps_t is drawn from a counter-based RNG (Philox or Threefry family, key width >= 128 bits) with key K = H(master seed, row ID, replicate index, seed index, role tag 'rewcorr-eps', root episode ID) and counter = t, the absolute episode step (A16 numbering, 1..H_V); H = SHA-256 over a fixed, length-prefixed canonical encoding, truncated to the key width; one fixed normal transform declared in the code freeze. A master seed is declared because A18 requires independently derived streams but defines none. Root episode ID: the integer minted exactly once when the scheduler starts a base (non-continuation) episode, its ordinal from 0 in the frozen episode schedule of its (row, replicate, seed), assigned at schedule-build time before any episode runs; never derived from wall clock, process/thread IDs, worker or completion order or branch counts; a re-run keeps its ID; every continuation (swap L/H, placebo clamp, pool draw, any intervention branch or branch of a branch) inherits the root of the trajectory it continues, for a swap the recipient's, never the donor's; donor and pool histories are base episodes with their own roots. Bans kept: no key uses the donor id within a continuation or a continuation-relative counter; eps never stored or transplanted; eps a function of the key only; z_t computed transiently, never written to the block, swap/clamp state or a probe-readable log; the role shares no state with any other RNG role, including the S-INT stream (R59(c)); no shared sequential stream. Collision bound N^2/2^129 at 128 bits; proposed S0 planted-violation audits for key distinctness, donor/counter keys, shared state, and stored eps or z. Also kept: SD(z) := SD(zeta) sqrt(1.01); PROXY keeps its CNA v3 L431 state law. Gate in exact form: 33 U_A < 1 (your L61: "The equivalent threshold is 1/33."), because 0.05/1.65 and 1/33 differ in the last float64 digit. Not yet fixed: the master seed value and the normal transform (before freeze).
