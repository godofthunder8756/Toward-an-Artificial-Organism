## Description
This software release provides the executable and reproducibility infrastructure for B2, the causal-maintenance experiment in Experimental Block I of the Theory of Everything Research Programme.

The package implements the publicly preregistered confirmatory design associated with OSF DOI 10.17605/OSF.IO/GQANP. It includes five maintenance architecture classes (passive persistence, external maintenance, internal feed-forward maintenance, reciprocal internal maintenance and a budget-matched brute-force bypass), seven frozen confirmatory manifests and locks, twenty held-out seeds, disturbance regimes, targeted C1 ablation, specific and irrelevant rescue interventions, provenance capture, integrity verification, automated tests and the registered confirmatory analysis.

The confirmatory study retained active-maintenance advantage (H1.1), internal autonomy after support withdrawal (H1.2), a topology-specific reciprocal maintenance effect (H1.3), and specific functional rescue (H1.4). Boundary/timescale robustness (H1.5) remained deferred. The budget-matched brute-force bypass satisfied every preregistered non-inferiority condition, so reciprocal closure-like topology was reduced as a necessity claim for the measured artificial maintenance capacity (H1.6).

The release includes an explicit packaging-repair audit. Before any confirmatory simulation data were generated, omitted Python import-support modules were restored from the previously validated development baseline; no frozen scientific specification changed. The public analysis script is path-portable but preserves the preregistered statistical logic and regenerates the original substantive analysis artefacts bit-for-bit from the companion dataset.

The scope is deliberately narrow: B2 supports artificial functional/causal maintenance within the registered three-component architecture family. It does not establish biological life, universal organisational closure, the historical origin of life, intelligence, consciousness, or universal necessity for Transition Problem 1.
