# Theory of Everything Research Programme
## Block V Reflective Self-Modelling Confirmatory Experiment Software and Reproducibility Package

**Version:** 1.0.0  
**Software DOI:** 10.5281/zenodo.23321474  
**Paired Dataset DOI:** 10.5281/zenodo.23321507  
**OSF preregistration:** 10.17605/OSF.IO/JZ4ED  
**Methodological framework:** 10.5281/zenodo.22857230

This package contains the executable and reproducibility infrastructure for the preregistered Block V confirmatory study.

The public preregistration was accepted on 9 October 2026 at 23:00 BST. Before any confirmatory execution, a post-registration audit identified two execution-level ambiguities. A clarification addendum was publicly accepted by OSF before any confirmatory seed was run. That clarification fixed the exact H5.1 matched self-irrelevant control and fixed utility as the primary H5.6 bypass metric.

Final preregistered decisions:

- H5.1 — RETAIN
- H5.2 — RETAIN
- H5.3 — RETAIN
- H5.4 — RESTRICT
- H5.5 — RETAIN
- H5.6 — REDUCE

The package preserves the frozen manifests and locks, confirmatory seeds, architecture definitions, intervention/bypass definitions, preregistration and clarification records, execution runner, provenance records, analysis code and reproduction checks.

The study supports a scoped causal role for self-related estimates in adaptive control, but H5.6 was REDUCE because externally supplied calibrated self-relevant confidence reproduced the registered downstream control function closely enough to defeat a stronger endogenous-necessity claim.

No result in this package establishes phenomenal consciousness, subjective experience, sentience or human-like selfhood.
