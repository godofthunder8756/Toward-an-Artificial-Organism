This deposit candidate presents and validates a causal assay in an engineered finite reference construction. The exact maximum supported claim is:

> In the registered finite construction, a relationally self-indexed temporal state causally influenced future-directed choice through the separately intervened prospective-evaluation path.

The construction holds event content separate from represented ownership and uses explicit engineered variables for event memory, a relational `SELF`/`OTHER`/`UNBOUND` tag, present state, deterministic prospective option evaluation, and deterministic selection. The registered intervention set covers self/other attribution (S1), self-history substitution (S2), attribution ablation (S3), prospective-coupling ablation (S4), complete-state restoration (S5), false-self/origin exclusion (S6), a mediator clamp, and a direct downstream selector clamp.

The principal contribution is the assay protocol, explicit causal routing, transparent reference implementation, and fail-closed evidence discipline. Several expected outputs are algebraic consequences of the registered equations and option construction; the result is therefore framed as validation of an engineered reference assay rather than discovery of a spontaneous mechanism or autonomous self-model.

The accepted campaign used six fresh-process deterministic re-executions in alternating forward/reversed order. Each execution contained 88 registered cases. Across all six there were 528 case instances and 1,752 trace endpoints. Each endpoint was read without mutation 256 times, giving 448,512 stored probe records. The repeated reads are not independent observations, and the six same-implementation runs establish deterministic reproducibility and order/token invariance rather than six independent scientific replications.

S5 produced a byte-identical complete-state restoration and an identical deterministic continuation endpoint/read-only projection within this construction. S6 is an origin-exclusion and infrastructure control because true origin is not supplied to the core. P_CLAMP is a direct mediator positive control. Q_CLAMP is a deliberately direct selector control and has no persistence-probe series.

The public package supports verification of one normalized 88-case projection and fresh execution of the minimal reference construction. It does not contain the six large historical raw arrays and cannot reconstruct the complete historical campaign. `SITC_D0_ARCHITECTURE.md` is disclosed by filename, recorded size, and SHA-256 but withheld because its exact bytes contain unpublished cross-project architecture material outside the authorized public boundary. The deposit is therefore a public verification/reference package, not a complete historical freeze reconstruction.

The preregistration was prospectively frozen within the recorded project provenance. It did not receive an independent third-party timestamp before outcome-bearing execution. The package preserves this limitation and does not create a retrospective external timestamp claim.
