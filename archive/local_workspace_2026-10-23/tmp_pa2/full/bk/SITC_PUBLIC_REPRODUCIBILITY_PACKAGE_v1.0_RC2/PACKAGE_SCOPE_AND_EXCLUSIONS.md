## Positive scope

The RC2 package is designed to let a reviewer:

1. verify the hashes and identity of the separately supplied authoritative English manuscript and faithful Hungarian companion;
2. inspect the public frozen causal specification;
3. verify hashes and re-score the single normalized 88-case projection;
4. inspect the actual evidentiary role and algebraic dependence of S1-S6, P_CLAMP, and Q_CLAMP;
5. run the minimal engineered finite reference construction in new processes; and
6. audit the publication boundary, provenance statements, licensing, and prior-art framing.

The package supports only this maximum positive claim:

> In the registered finite construction, a relationally self-indexed temporal state causally influenced future-directed choice through the separately intervened prospective-evaluation path.

`SELF`, self-history, present state, prospective evaluation, and choice are explicit engineered variables or computations. The package validates the registered causal-assay routing and implementation behavior of a finite transparent construction. It does not report the discovery of an autonomous or spontaneously formed self-model.

## Historical evidence boundary

The compact package includes one canonical normalized projection, public hashes, and accepted compact receipts. It does not expose all historical raw data needed to independently reconstruct the six-run campaign. A reviewer can verify normalized evidence and run the public reference implementation, but must not report either operation as a reconstruction of the historical campaign.

The project provenance internally froze the preregistration before outcome-bearing execution. No independent third-party timestamp anchored that freeze at the time. RC2 preserves the internal hash chain and states this limitation; it does not create a retrospective external timestamp claim.

## Evidentiary and statistical boundary

The 448,512 stored probe records are 1,752 trace endpoints read 256 times without mutation. They are not 448,512 independent observations. The six accepted processes are deterministic same-implementation re-executions that test reproducibility, forward/reversed ordering, and token mapping. They are not six independent scientific replications.

Several outcomes follow algebraically from registered equations and option construction. RC2 therefore presents the contribution as validation of an engineered causal assay and its evidence discipline. S5 establishes byte-identical restoration plus an identical deterministic continuation endpoint/read-only projection in this implementation. S6 is an origin-exclusion/infrastructure control because true origin is not an input to the core. Q_CLAMP is a direct downstream selector control without a persistence-probe series.
