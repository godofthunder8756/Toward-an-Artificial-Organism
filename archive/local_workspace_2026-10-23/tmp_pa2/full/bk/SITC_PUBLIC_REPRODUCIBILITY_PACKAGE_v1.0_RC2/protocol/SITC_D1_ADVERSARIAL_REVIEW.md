## Mediation requirements

Correlated changes at every layer are insufficient. Two explicit clamps are mandatory:

- `P_CLAMP`: different E/R histories are assigned the same registered P immediately before prospective evaluation. F, Q and choice must then be identical.
- `Q_CLAMP`: different upstream P values are paired with the same registered Q vector immediately before selection. Choice must then be identical.

S4 additionally removes only the P-to-future-evaluation edge. It must leave the stored E, R, H and P byte-identical and preserve ordinary option comparison around the registered reference state.

## S1–S6 interpretation

- S1 identifies the effect of represented ownership while holding factual content fixed.
- S2 tests whether the downstream path follows a transplanted self-history representation rather than recipient identity.
- S3 tests whether the ownership relation is necessary while factual memory remains available.
- S4 tests whether self-history affects choice through prospective evaluation.
- S5 tests recovery of the complete declared temporal state after a divergent intervention, with sham and content-only restoration controls.
- S6 tests represented ownership against external true origin. A falsely self-attributed other-origin event is predicted to act like an equivalently represented self event because true origin is deliberately unavailable to the actor. This is attribution causality, not accurate self-knowledge.

## Residual limits

A finite transparent construction cannot rule out an extensionally equivalent lookup implementation of the same mapping. Stable P is also a form of memory. The admissible conclusion is therefore limited to the registered causal organization: a relationally self-indexed temporal state influenced future-directed choice through the separately intervened prospective path.

No positive subset may support the terminal claim. Every S1–S6 family, both clamps, all specificity controls, all six process replications, both orders, and all integrity gates must pass.
