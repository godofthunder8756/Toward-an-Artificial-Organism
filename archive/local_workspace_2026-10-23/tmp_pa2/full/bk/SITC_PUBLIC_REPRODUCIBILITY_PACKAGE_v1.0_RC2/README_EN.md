## Quantitative accounting

Each of the six accepted fresh-process deterministic re-executions contained 88 registered cases. Across the six executions there were 528 case instances and 1,752 trace endpoints. Each endpoint was read without mutation 256 times, producing 448,512 stored probe records. Those 256 repeated reads do not constitute 256 independent observations, and the six same-implementation executions are evidence of deterministic reproducibility and order/token invariance rather than six independent scientific replications.

The compact package does not contain the six large historical raw arrays. It contains the normalized projection, its hash bindings, and the accepted summary receipts. Therefore it cannot by itself reconstruct the historical campaign from raw outcomes.

## Four reproducibility modes

1. **Normalized evidence verification** checks the frozen hashes, the single 88-case normalized projection, the published scoring rules, and the consistency of the compact summary records. It does not execute the mechanism or load the historical raw arrays.
2. **Public reference execution** runs the packaged transparent construction in new worker processes and compares newly produced normalized results with the published projection.
3. **Independent fresh rerun** requires another investigator or environment to execute and audit the public reference package independently. The package enables this mode; possession or local execution of the package alone is not an independent rerun.
4. **Historical reconstruction** would require the omitted historical raw arrays, original process-provenance records, exact historical command binding, and full frozen environment. This compact package does not support that mode.

See `integrity/PUBLIC_VERIFICATION_SCOPE.md` for the complete capability matrix.

## Quick verification

Python 3.10 or later is required. The verifier uses only the Python standard library.

```text
python /path/to/PACKAGE_ROOT/code/public_verify.py
```

Expected success status:

```text
PUBLIC_NORMALIZED_EVIDENCE_VERIFIED
```

This command verifies the normalized public evidence within its declared scope. It does not claim that the reference implementation was executed, that historical raw arrays were loaded, or that the historical campaign was reconstructed.

## Fresh public reference execution

```text
python /path/to/PACKAGE_ROOT/code/run_public_reference.py --output reference_output
```

The output directory must not already exist. This command launches six new child processes in the registered forward/reversed order and compares their normalized projections with the published projection. It creates a new public reference execution; it does not replay the historical campaign's operating-system provenance or command binding.
