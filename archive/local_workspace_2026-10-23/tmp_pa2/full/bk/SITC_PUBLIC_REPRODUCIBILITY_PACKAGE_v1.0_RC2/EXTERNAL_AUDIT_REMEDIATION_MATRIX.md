## Consolidated evidentiary-role correction

RC2 will not count the registered components as eight equally independent discoveries.

| Component | RC2 evidentiary role | Required interpretation |
|---|---|---|
| S1 | Target self/other attribution contrast and implementation-conformance check | The output follows the explicit relational tag in the engineered finite construction. |
| S2 | Substitution/interchange check | The downstream state follows an explicitly transplanted history variable; this is a controlled routing test, not spontaneous identity transfer. |
| S3 | Attribution-ablation check | Removing the explicit ownership relation removes the registered effect as entailed by the construction. |
| S4 | Prospective-coupling ablation and specificity check | Disconnecting the prospective path tests registered causal routing; only the preregistered specificity cells make the identified goal dependence visible. |
| S5 | Deterministic serialization/restoration check | Byte-identical restoration and trajectory recovery establish exact technical restoration in this construction, not selfhood or phenomenal continuity. |
| S6 | Origin-exclusion and infrastructure negative control | It shows invariance when true origin is not supplied to the core; it does not establish a general capacity to distinguish factual origin. |
| P_CLAMP | Mediator intervention positive control | A direct registered intervention on the mediator path; small panel, reported with its own denominator. |
| Q_CLAMP | Deliberately direct downstream selector control | A single-shot downstream control with no 256-step probe series; its result is intentionally tautological with respect to the supplied scores. |
