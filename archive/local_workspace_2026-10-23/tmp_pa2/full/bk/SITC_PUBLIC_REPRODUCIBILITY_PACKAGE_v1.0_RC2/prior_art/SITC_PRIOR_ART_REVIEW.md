# Prior-art review - RC2

**Work:** *Validating a Causal Assay for Engineered Self-Indexed Temporal State*  
**Reserved DOI:** `10.5281/zenodo.22863692`  
**Review date:** 2026-09-20  
**Review status:** `NOVELTY = UNADJUDICATED`  
**Scope:** Focused, adversarial comparison with primary work on autobiographical and episodic memory, self/other representation, prospection and action selection, causal mediation, interchange intervention, causal tracing, and activation patching. This is not a systematic review, a priority search, a patentability opinion, or evidence of peer review.

## Canonical claim and construction boundary

The maximum claim frozen in the preregistration is reproduced exactly:

> In the registered finite construction, a relationally self-indexed temporal state causally influenced future-directed choice through the separately intervened prospective-evaluation path.

Every part of this sentence constrains its interpretation. The subject is a registered finite construction, not an autonomous or naturally occurring agent. `SELF` is an engineered relational tag produced by equality between an attributed-owner token and a controlled-entity token. Event content is carried explicitly. The present state is produced by a specified deterministic rule. The prospective evaluator and selector are engineered and transparent. The demonstrated dependencies follow the constructed causal graph under the registered interventions.

The appropriate contribution category is therefore an **assay/protocol and evidence-discipline contribution using a transparent finite reference construction**. The work does not claim an architecturally novel self-model, spontaneous self-indexing, autonomous autobiographical organization, learned temporal identity, or emergent prospective cognition.

## Adversarial reduction of the RC2 construction

The mechanism admits a compact algebraic description. Let `r = 1` when the attributed-owner token equals the controlled-entity token and `r = 0` otherwise. For event content `e`, the present-state variable is `p = r * e`. For option `i` with registered offset `d_i` and goal `g`, the prospective evaluator computes `F_i = p_eff + d_i` and `Q_i = -(F_i - g)^2`; the selector chooses the unique maximum `Q_i`. Under normal coupling, `p_eff = p`; under the prospective-coupling ablation, `p_eff = 0`. The target options are constructed as `d_COMPENSATE = g - e` and `d_BASELINE = g`.

It follows algebraically that the target-panel margin is:

`Q_COMPENSATE - Q_BASELINE = 2 * e * p_eff - e^2`.

Thus `SELF` gives `p_eff = e` and selects `COMPENSATE` by `e^2`, while `OTHER`, `UNBOUND`, and the S4 coupling ablation give `p_eff = 0` and select `BASELINE` by `e^2`. These results are intended consequences of the construction. They are useful for validating whether the harness, interventions, records, and analyzer implement the registered causal graph. They are not discoveries that an independently trained or evolved system spontaneously developed self-indexed temporal causality.

This reduction also identifies factors that are inactive for the principal target-panel decision:

- the relation and event content are active only through the engineered `p` and `p_eff` path;
- goal cancels from the target-panel margin because the option deltas are defined relative to that goal;
- content sign changes intermediate values but not the registered winner or absolute winning margin;
- presentation order is inert once choices are interpreted semantically;
- the literal token strings are inert after the equality relation is resolved;
- event key and tick affect serialized state or provenance but do not enter the evaluator;
- after the P clamp, upstream differences are intentionally downstream-inert;
- after the Q clamp, every upstream variable is intentionally selector-inert.

The registered cases therefore should not be described as a large set of independent behavioral discoveries. They are deterministic checks over a small number of effective decision structures, with many crossed controls and repeated read-only probes used to test implementation integrity, invariance, and persistence.

## What each intervention can and cannot establish

| Registered element | Legitimate evidentiary role | Design consequence or residual alternative |
|---|---|---|
| S1 - self versus other attribution | Verifies that changing only the represented ownership relation changes `p`, future values, and the semantic choice as registered. | Because the relation resolver and state rule are explicit, the result is largely entailed by `p = r * e`; it does not show an emergent or truth-sensitive self-representation. |
| S2 - self-history swap | Verifies that the recipient's declared downstream state and choice follow the transplanted actor-local history under the registered swap. | Interchange intervention is established prior art, and the outcome follows the explicit state-update equation. It cannot exclude every extensionally equivalent lookup implementation. |
| S3 - attribution ablation | Confirms that removing the relation while preserving factual event bytes disables the registered pathway, and that clamping `p` can restore its downstream consequence. | The ablation directly changes an input to the state equation. This is a pathway check, not evidence that factual memory and self-attribution are naturally separable in other systems. |
| S4 - prospective-coupling ablation | Confirms that stored `p` does not affect choice when the registered `p -> F/Q` edge is cut, while specificity panels exercise the evaluator under the ablation. | Setting `p_eff = 0` directly removes the only registered upstream influence. The result rules against the preregistered direct-owner/history policy inside this harness, not all possible hidden policies in arbitrary systems. |
| S5 - complete-state restoration | Checks byte-identical restoration of the declared state and equality of the deterministic continuation endpoint/probe projection to the direct arm. | Restoration is a technical property of the declared finite state. In the public implementation, sham and content-only arms collapse to the same effective divergent condition because the divergence changes history/state rather than event content; they are not independent controls. Repeated read-only probes do not constitute evolving observations. |
| S6 - false-self control | Confirms that outputs group by represented attribution when external true origin is excluded from the core inputs. | Because true origin never enters the actor computation, invariance to origin is an input-isolation/logger control and a design consequence. It does not show accurate or inaccurate factual self-knowledge. |
| P clamp | Checks that two upstream histories yield the same future values and choice once the declared present mediator is fixed. | Equality downstream of a complete deterministic clamp is expected by construction; it supports implementation fidelity, not discovery of a latent mediator. |
| Q clamp | Checks selector behavior under a fixed semantic value vector. | This directly tests the selector only. With no state-trajectory probes in this arm, it supplies no additional evidence about upstream temporal state. |

## Simpler explanations and what remains unresolved

The assay was designed to distinguish several registered alternatives, but its finite deterministic form leaves broader equivalents open.

- **Ordinary memory:** S1 and S3 separate factual content bytes from the owner relation inside the declared ontology. They show that content alone is not sufficient in this implementation. They do not show that a richer content representation could not encode the same relation implicitly.
- **Agent-ID lookup:** Opaque token permutations show invariance to particular literal identifiers. They do not eliminate a relational equality lookup, because that lookup is exactly how `SELF` is engineered.
- **Hidden policy state:** The transparent signatures, fresh instances, clamps, and exact normalized outputs constrain undeclared state in the released reference construction. They do not prove that every behaviorally equivalent implementation must use the same internal decomposition.
- **Action-conditioned state and reward contamination:** The finite reference implementation excludes action history and undeclared reward inputs from the evaluator and selector. This is a code-level boundary, not a general empirical finding about learned agents.
- **Execution-order leakage and numerical artifacts:** Forward/reversed ordering, exact integer arithmetic, fresh processes, and byte-level comparisons test these implementation risks. These are integrity controls rather than independent causal replications.
- **Tautological success:** Several contrasts set or remove the only registered causal input and then verify the predetermined deterministic consequence. Such outcomes validate the assay plumbing and its evidence trail. They do not, by themselves, make the mechanism theoretically surprising.

## Assessment of the contribution

Substantial component-level prior art exists for every broad ingredient:

1. autobiographical or episodic memory in artificial agents;
2. self/other distinctions and explicit agent roles;
3. history-dependent action and value selection;
4. simulation or prediction of future outcomes;
5. causal mediation, representation swaps, ablations, causal tracing, restoration, and activation patching;
6. preregistered controls and deterministic reproducibility checks.

No architectural novelty should be inferred from recombining those ingredients in a small deterministic program. The supported contribution is narrower: the work gives a transparent reference assay that prospectively separates event content from represented ownership, exposes a declared mediator path, applies matched swap/ablation/restoration/clamp controls, and binds the resulting evidence to frozen decision rules and integrity records. This makes the construction useful as a test fixture for causal-identification practice and as an auditable example of how to avoid promoting generic `history -> action` behavior into a self-related claim.

The conjunction of S1-S6 and the clamp controls may be practically useful as an evaluation protocol. This focused review did not locate an earlier artifact with the identical registered panel and evidence pipeline. That negative search result is not evidence of priority. Terminology varies across causal interpretability, cognitive robotics, autobiographical memory, reinforcement learning, and computational self-modeling, and an extensionally similar protocol may exist under different names.

Accordingly:

`NOVELTY = UNADJUDICATED`

The package makes no claim of novelty, priority, patentability, or first demonstration.

## Claim exclusions

The registered result does **not** establish or support claims of:

- phenomenal consciousness;
- sentience or subjective experience;
- personhood or life;
- AGI or general intelligence;
- human-equivalent selfhood;
- metaphysical identity or token continuity;
- accurate factual self-knowledge;
- spontaneous, emergent, or autonomous self-model formation;
- architectural novelty.

It also does not establish that the engineered variables correspond to human autobiographical memory, autonoetic consciousness, narrative identity, or an independently learned temporal self. Terms such as `self-history`, `SELF`, and `self-indexed` name registered functional roles in the construction.

## Publication interpretation

If released under the reserved DOI, the work should be described as a methods and reproducibility report for a finite engineered causal assay. The title, abstract, metadata, README, and repository description should keep the canonical claim unchanged or use a strictly weaker paraphrase. They should disclose the deterministic equations, the relational equality resolver, active and inert factors, design-consequence controls, and the limits of repeated probes and fresh-process runs.

Deposit readiness, hash verification, or successful execution would not adjudicate novelty and would not convert the reference construction into evidence for consciousness or selfhood. `NOVELTY = UNADJUDICATED` remains the only permitted novelty status unless a separate, broader prior-art process supports a later human decision.

## Review limitations

This review is deliberately focused. It is based on the cited primary papers and official proceedings or author manuscripts available on the open web, together with the RC1 source list. It did not search every bibliographic database, dissertation, workshop archive, patent collection, code repository, or non-English literature. Several adjacent fields use overlapping constructs with inconsistent terminology. The review can therefore establish substantial component-level overlap and a conservative claim boundary; it cannot establish absence of an exact precursor.
