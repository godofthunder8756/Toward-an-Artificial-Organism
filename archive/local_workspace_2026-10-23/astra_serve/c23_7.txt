## 5. Interventions and causal criteria [replaces DRAFT Sec.5]

### 5.1 Intervention set (identical for candidate and rivals)

| Id | Intervention |
| --- | --- |
| I-SYS / I-EVID | Force Z_t = S or Z_t = E at a declared time. The pair is matched on default first-order information exactly (D1, L1). |
| I-SWAP | Replace the candidate's assessment content with its value from a donor history, specified independently of evaluation outcomes (Sec.5.3). |
| I-CORRUPT | Clamp the assessment content to a prespecified value. |
| I-RESCUE | The credited rescue **must reverse the assessment-dependent downstream consequence in the declared causal procedure**. Restore-and-rerun identity is an integrity check only (Astra Q5). [v3] Executable sequence: spec v2 Sec.4.5. |
| I-COST | Generalization probe only (Sec.4.3). |
| I-HEAD | Action-head lesion. Recorded, not credited. |

### 5.2 First-order controls: three categories; tolerances illustrative (Astra Q4, edit 4)

**Astra edit 4 (verbatim):** "C-FO establishes preservation only over the prespecified first-order probe battery. Output preservation alone is not described as preservation of the full first-order state. Direct inference effects under matched subsequent observations are reported separately and constrain the dissociation claim."

The three effects are separated and reported separately (consult #21, Q4):
1. **Downstream prediction changes caused by selecting different checks.** These are expected consequences of the intervention, and are reported.
2. **Direct prediction changes under identical check observations.** The intervention changes pa given the same y and y' (the D5 precision route). "The second category limits the dissociation claim; it cannot simply be declared irrelevant."
3. **Changes in checking while a prespecified first-order probe battery is preserved.** The battery is the pre-check p0 on every read pattern x a fixed history bank. Only this category supports C-SEL, and only to the extent category 2 permits.

**Tolerances: ILLUSTRATIVE, not proposed for freezing.** delta_p = 0.02, delta_acc = 0.005 and delta_LL = 2% are retained as placeholders only. Consult #21 (verbatim): "A maximum probability change of 0.02 can matter substantially to checking decisions; the demonstrated whole-trial value gap is only about 0.006. Freeze margins only after determining whether tolerated prediction changes could explain the checking effect."
