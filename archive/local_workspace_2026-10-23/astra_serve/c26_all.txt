## 3. Check 3: Delta_M = 0 and the empty donors. **Both are real properties of the reference at the frozen settings, not implementation bugs. Both expose a spec design gap: criterion attainability at K_SEP was not checked before freeze.**

Hand derivations use only spec Sec.0-Sec.4 and emitted numbers.

**Facts used.**
- (F1) eps = w + e - 2we = 23/100 in both regimes (spec Sec.0.1; ITEM-1 "eps = 23/100 in both regimes"). So P(split read) = 1 - (0.773 + 0.233) = 0.5313 in both regimes.
- (F2) Admission v3.2 D1/L1: TV(X, y) = 0 and TV(X, y, y'') = 0. PREDICT and RESAMPLE observations carry no Z information, and only RECHECK moves the belief (Sec.3.1: "L_S = L_E for P and M, so the belief changes only after R"). ITEM-1 VERIFIED this for histories up to length 3.
- (F3) On a split read, PREDICT correctness g_P = 1 - eps = 77/100 (majority of a 2-1 read; hand-computable). RESAMPLE correctness g_M is Z-independent by (F2) and equals the emitted lambda_M = **432817/500000** (~= 0.865634). lambda_M = E[m_M(H)] is history-independent because m_M is, and it is identical in all four settings in `ITEM-8.json`. So g_M - g_P = 47817/500000 ~= 0.095634.
- (F4) For the Bayes planner, M and P leave the belief unchanged (F2), so they have the same continuation value at every (t, b).

[c26 part 7/12]
**(a) Delta_M = 0 at (c_R, c_S) = (1/100, 1/10): forced at every horizon.** By (F4), Q_M - Q_P = (g_M - c_S) - g_P = 0.095634 - 0.1 < 0 at every trial, belief and horizon. The tie rule P ? R ? M does not matter because the inequality is strict. So R-HAC-MB never takes M at this cost pair, E[#M | Z] = 0 for both Z, and Delta_M = 0 exactly for any T_SEP. C-REF requires Delta_M >= 1/100 and is **unattainable by the reference at this cost pair at every horizon**. The one-trial inequality uses only spec constants and could have been checked before freeze. The emitted `cref_counts` show E[#M] = 0/1 under both Z at T_SEP = 3 and 4, consistent with this. Classification: **real property of the reference; spec design flaw (an unattainable conjunct in a chosen setting); not an implementation bug.**

**(b) Empty donors at (1/50, 3/50).** The emitted `cref_counts` are [[0, 15939/10000], [0, 15939/10000]] at T = 3 and [[0, 5313/2500], x2] at T = 4. That is E[#M] = T x 0.5313 under both Z and E[#R] = 0: the reference takes M on every split read and never R. So:
1. No RECHECK means no belief movement (F2). Every reachable history at layer tau has the empty LR-class multiset. The reachable donor set is one state, so S-donor = E-donor = the empty vector. NO INTERVENTION CONTRAST follows from the Sec.4.2 donor construction; it is not a donor-search bug.
2. The action law depends only on (t, y), and P(y) is Z-independent (F1). So E[#R | Z] and E[#M | Z] are Z-independent and Delta_R = Delta_M = 0 exactly.
3. b == 1/2 means m_a(H) equals the prior-marginal g0_a(r), so E_err(baseline) = 0 exactly and C-T2 hits the named boundary case.

Why M wins at the prior: myopically, g_M - 3/50 ~= 0.80563 > g_R(1/2) - 1/50, where g_R(1/2) = 1/2(kappa_R(S) + kappa_R(E)) ~= 0.81247 by hand from Sec.0 (so ~= 0.79247). The extra information value of R is not enough at T <= 4. This is a standard exploration trap: the only informative action is dominated at the prior, so the planner never learns the regime, even though M is the better action in E and R the better action in S. That M beats R *including* continuation at T_SEP <= 4 is what the emitted counts show. ADVISORY (pre-steering) cross-check: the independent planner reproduced these counts exactly (t=1 split-read Q: M 2.574767 > R 2.565623 > P 2.539133 at T = 3). Whether the trap persists at longer horizons is **NEEDS-APPROVED-RERUN** (or a hand bound, not attempted). It does not affect any frozen label, because A-SEP is frozen at T_SEP  in  {3, 4}.

Classification: **real property of the reference at the frozen (T_SEP, cost) settings; spec design gap (no pre-freeze check that the reference generates a donor contrast); not an implementation bug.**

[c26 part 8/12]
**(c) Is C-REF's M-conjunct reachable at all?** By (F2) and (F4), M's value never depends on b. So Delta_M > 0 can only arise indirectly: R's belief-dependent value falls below M's after the agent has *already rechecked* and its belief has moved toward E.
