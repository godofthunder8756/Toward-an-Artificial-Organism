# E3 design candidate: preserving the information that defines the individual

Status: proposed mechanism and protocol; not implemented or shown to work.
The E2 diagnostic motivates this direction. This is not a discovery about
consciousness or a claim of originality.

## The remaining bypass

E2 makes material determine which neural computations can operate. But learned
signed weights remain intact in ordinary host arrays while simulated tissue
wears away. Restoration of biomass can expose exactly the old connections.
The experimenter preserved the agent-specific organization, even if the
simulated agent did not. Such a model can test regulation; it cannot test
maintenance of its own learned information.

The important boundary is between generic simulator laws (which every model
requires), inherited generic learning machinery (which can be declared), and
externally preserved *individual-specific acquired information*. E3 should
remove that last bypass. Biological inheritance and environmental support do
not invalidate self-maintenance; an undeclared perfect backup of every learned
connection would invalidate this particular test.

## Concrete candidate mechanism

Represent a connection using several spatially separated, metabolically
maintained noisy traces instead of a protected real-valued weight. Transmission
uses their current locally reconstructed estimate. Generic local update rules
can consolidate redundant traces using activity and feedback; no evaluator
keeps an uncorrupted copy accessible to the agent. Short evaluation backups
exist only for controlled experimenter counterfactuals.

Material deficit causes measurable trace diffusion and occasional local loss,
not just reversible signal attenuation. Repair supplies capacity to rewrite
traces, but supplies no missing bits or target values. Which traces are worth
preserving must depend on their acquired function. Local eligibility can
connect recent activity and maintenance to subsequent energy consequences.

A candidate maintenance score can combine:

- predicted loss of task-relevant capability from degrading a trace;
- the cost of reconstructing it from other still-present traces;
- whether the same information remains useful under current opportunities.

These are proposed computational estimates. A privileged true performance
counterfactual is an **oracle control**, not an input available to the agent.
We should initially compare simple reward-modulated eligibility, fixed generic
error correction, and ordinary recurrent reinforcement learning on this plant.
Only later test a learned maintenance allocator; otherwise its advantage could
come from richer feedback or an invulnerable second controller.

## Small executable target for the next iteration

A streaming delayed-association task with newly learned associations. Start
with neutral random traces. Use the same maintained substrate for recall,
resource choice and consolidation actions. No text training. Distinct resource
chemistries can support traces, routing and write operations; declare all costs.
All variants receive identical observations and scalar feedback. Use explicit
training rewards initially and report them rather than presenting direction as
uncaused or reward-free.

A phase that forbids new association examples is decisive. Recovery after
partial trace loss must come from still-present distributed information; it
cannot be explained by re-teaching the answer. Recovery after complete
information loss should fail: recovering arbitrary deleted bits without any
source would indicate a leak, not superior self-maintenance.

## Interventions and rival explanations

| Intervention | What it separates |
| --- | --- |
| Partial trace damage; examples withheld | Repair from redundancy versus external relearning |
| Restore material but do not restore trace values | Material viability versus preserved organization |
| Supply an exact protected template to a control | Advantage due to privileged information |
| Freeze consolidation while preserving inference | Ongoing information maintenance versus fixed computation |
| Make a learned association irrelevant | Selective relinquishment versus indiscriminate copying |
| Permute resource chemistry without announcing it | Learning functional dependency versus fixed resource labels |
| Match redundancy and compare ordinary error correction | New adaptive benefit versus a standard code |
| Remove all copies and all external clues | Information-leak negative control; recovery should be at chance |

Primary candidate evidence: resource allocation protects useful acquired
information, enables within-life recovery without examples, and stops paying
for information that loses its function while remaining viable. Count acquired
information and actual material costs; survival alone is insufficient. The
same information budget and access are essential across rivals.

If conventional error correction plus reinforcement learning explains all
outcomes, retain that explanation. If local reconstruction adds an advantage,
that establishes a functional maintenance mechanism under these conditions.
Neither outcome establishes felt craving, phenomenal continuity or consciousness.

## Prior-art obligations before implementation claims

Review continual learning, synaptic consolidation, palimpsest memory, fault-
tolerant neural computation, active inference, adaptive error correction, and
lifelong neural developmental programs. This proposal combines established
ideas. The possible contribution is a new controlled demonstration or mechanism,
not the generic claim that useful information must be preserved.
